# POR QUÉ ESTÁN APARTE
# La imagen del `agente` (Dockerfile) no sirve la voz: el webhook de WhatsApp y
# los barridos corren ahí, y el relay corre en su propio servicio. Meter esto
# en requirements.txt le agrega a esa imagen una dependencia que no usa —y que
# rompe su build, porque `pip install git+...` necesita un `git` que la imagen
# no tiene y no tiene por qué tener—.
#
# El import de `calling_agent` está adentro de `app/voz/agente.py::para_llamada`
# justamente para esto: sin este archivo instalado, todo lo demás arranca igual.

-r requirements.txt
